## 1. Hospital Management System

### Description
A relational database designed to manage core operations of a hospital.  
It stores and manages information about patients, doctors, appointments, treatments, and billing.

### Tables
- **patients** – Patient personal and contact details  
- **doctors** – Doctor information and specialization  
- **appointments** – Appointment scheduling between patients and doctors  
- **treatments** – Medical treatments linked to appointments  
- **billing** – Billing and payment records  

### Key Features
- Patient and doctor management  
- Appointment scheduling and status tracking  
- Treatment records with cost  
- Billing system linked to treatments and appointments  

### How to Use
1. Open MySQL Workbench or any MySQL client  
2. Create a new schema (optional)  
3. Run the `hospital.sql` file to import the complete database
